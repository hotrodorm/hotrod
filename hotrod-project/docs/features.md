# Highlights of HotRod 5 ORM

As developers ourselves we started HotRod when we decided that we didn't like any of the available ORM solutions at the time.

The initial goal of HotRod was to speed up the development of phase an app. This included quick prototyping and also enhance the support for the gradual growth of the apps. That is, when a project just starts schema discovery gives an edge to the team; then, when the projects grows, LiveSQL, Dynamic SQL, and Nitro can implement complex functionality with little effort.

Later on, we realized we also wanted to reduce the operational cost of the apps. Apart from the coding phase we decided to consider the debugging, testing, support, maintenance, and above all the stability of the apps themselves. That's where Torcs, SQL Injection safety, API simplification, compile-time syntax checks, and many others features came into play.


## A. Top-of-the-Line ORM Features

The list of top of the line ORM features that we don't find in the competitors. We believe HotRod shines with these features:

1. Schema Discovery that Generate a Full Persistence Layer in Minutes
2. Out-of-the-box CRUD for Quick Prototyping and More
3. Feature-Rich LiveSQL including Tuples and Meta-Expressions
4. Advanced Type Resolution Mechanics for Column Types
5. Layout &amp; Model Entities
6. Out-of-the-box Cursors to Stream Data from Selects
7. Detection of Slow SQL Performance and Retrieval of Query Execution Plans
8. Dynamic SQL queries that change shape according to the runtime parameters
9. Multiple Optimistic Locking Strategies in CRUD
